# Fury Stat Lab: ревизия и атрибуция урона, 27.10.2026

## Уточнение отображения после ревизии

Разделение по характеристикам теперь описывает используемые моделью рейтинги, а не подтверждённый тип атаки на сервере. Периодические события с известным оружием записываются в соответствующую группу по аргументу расчёта; смешанные события, в том числе взрыв метки, остаются неразделёнными. По умолчанию показывается распределение по источникам. Это изменение не меняет формулу и не подтверждает её корректность. Сверка актуальной RU-механики DoT, метки и отрицательного сопротивления остаётся открытой; TL Build в ходе повторной проверки ограничивал доступ автоматическому чтению.

## Изменения

1. `damageEvents` уже записывал итоговые величины. Добавлены только признаки и аналитическое разделение основной/парной руки внутри события. `damageBreakdown` агрегирует те же события один раз; `markPool` остаётся внутренним накопителем и не создаёт дополнительную строку урона. Значения до классификации сохранены в `tests/fixtures/pre-attribution-20261027.json`: 777335.3185623853 суммарного урона в контрольном сценарии. Это синтетический прогон, не игровой эталон.
2. Тип прямой атаки и автоатаки показывается **по выбору характеристик в модели** (Wand → magic, Crossbow → ranged), не как проверенный серверный факт. Периодика, детонация, эффекты оружия и прочие неоднозначные случаи остаются `unverified`, пока нет надёжного подтверждения. Проклятие не становится Magic автоматически из названия. Модельный тип можно проверить в данных события `modeledType`.
3. Независимые разрезы: тип, механизм, источник, DoT и рука. Доли DoT — от общего урона; недостающая часть шкалы — остальные механики. Детали источника показывают модельные входы и объединяют события, а не прибавляют их второй раз. Компоненты, рассчитанные одним неделимым значением, не подделываются ради графика.
4. Сравнение характеристик повторно вызывает тот же симулятор с одним изменённым полем, тем же составом и правилами ротации. Изменение статов может изменить фактические моменты применения. +5 п.п. к базовому шансу парной атаки применяется до относительных модификаторов; параметр не равен +5 п.п. итогового шанса.
5. «Час преодоления»: исправлено старое значение +80 на +220 согласно имеющемуся в каталоге русскому описанию. Это исправление данных, не новая формула. Игровой RU Epic 5 и длительность специализации необходимо подтвердить скриншотом/замером.

## Матрица источников

| Событие | Механика | Тип для диаграммы | Основание / ограничения |
|---|---|---|---|
| Auto Crossbow/Wand | auto | ranged/magic по модели | `expectedHit` выбирает соответствующее оружие; отдельные расчётные main/off части |
| Прямые умения арбалета/жезла | direct | ranged/magic по модели | `direct(s)` использует `s.weapon`; серверная классификация может отличаться |
| Касание / Ритуальный круг | dot / curse | unverified | тики `dots`, моделируются через характеристики жезла; проверка типов DoT и множителей не завершена |
| Горение Гнева природы | dot / burning | unverified | тик `extraDots`; вид подтверждается описанием, тип и порядок характеристик требуют теста |
| Бел’Адир / отравленный болт / аспид | dot / poison | unverified | вероятность/тики приняты моделью; тип и крит/мощная на RU требуют теста |
| Мор Тевента / Перст | dot / curse | unverified | рассчитаны `dotsFromWeapons`/`extraDots`, независимая проверка необходима |
| Бедственное слово: прямой удар | direct | magic по модели | `direct` использует жезл и сохраняет существующие коэффициенты |
| Детонация DoT, метка, Шквал, Браука, Вердикт | explosion | unverified | применяется уже рассчитанное значение; нельзя автоматически приписывать взрыву атаку жезла/арбалета |
| Снаряд Гнева, молния, добавочные попадания метки/пассивок | additional | по модели при известном оружии, иначе unverified | не утверждает независимое попадание там, где источник вычислен агрегированно |
| Дополнительный снаряд оружия | weapon | unverified | идентификатор виден, отдельный игровой тип не подтверждён |
| Общее мастерство и контратака | other | unverified | используется существующая модель; часть событий не разделена по оружию или не имеет точного RU-коэффициента |

При суммировании `attackType`, `mechanism`, `source` и `hand` каждая сумма равна общему урону; DoT — подмножество по механике. `main/off` выделены только там, где исходный расчёт возвращал обе компоненты; другие эффекты отображаются как не разделённые. Модификаторы — входы модели, не отдельные источники DPS. Конкретные реальные срабатывания крита/мощной атаки не восстанавливаются из среднего значения.

## Следующие игровые тесты

1. Зафиксировать один билд, цель, позицию, бафы, время боя и урон до/после +100 крит или мощной атаки каждого оружия; сравнивать не разные билды с различными настройками.
2. С известным boost и одинаковой целью сравнить контрольные попадания без «Часа», с дебафом на цель и с +220 на себя. Повторить при известном ненулевом сопротивлении; записать вероятность и возможность отрицательного сопротивления.
3. Снять длительный лог одиночного «Касания», обновление 1/2/3 уровней и детонацию с/без «Темнословия»; отдельно проверить яд Бел’Адир, воспламенение и Тевента.
4. На цели с выключенными внешними источниками урона сопоставить входящие попадания и накопление/взрыв метки, в том числе повторное наложение и крит/мощную атаку взрыва.
5. Измерить частоту сокращений под «Отрешённостью» с одним и повторными уровнями каждого ослабления; сверить события с ограничением 10/с и исключением её собственного отката.

## Ограничения проверки

Автоматические тесты проверяют сохранность функций, согласование сумм и снимки данных; они не устанавливают настоящую формулу RU-сервера. Проверка новых диаграмм в живом браузере в этой среде ограничена недоступностью локального HTTP-сервера из облачного браузера. Перед слиянием необходима визуальная проверка отдельной ветки и независимый игровой замер для спорных механик. Эта ветка не публикуется на GitHub Pages.
