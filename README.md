# Fury Stat Lab

Fury Lab — калькулятор персонажа **Throne and Liberty** для связки **Crossbow + Wand**.

## Статус

Текущая рабочая версия: **v0.1.0-dev**.

Сейчас восстанавливается интерфейс и математическая модель исходного Fury Lab. Основная разработка ведётся в ветке `develop`.

## Что уже есть

- каркас интерфейса Fury Lab;
- экипировка на 13 слотов;
- панель активных / пассивных / защитного умения;
- распределение 54 очков характеристик;
- ручной ввод боевых характеристик;
- техническая 300-секундная симуляция;
- базовые regression-тесты симулятора.

## Важно

Текущий DPS в `develop` — технический placeholder. Он пока не является восстановленным DPS исходного сайта. До подтверждения RU-механик спорные формулы и эффекты не считаются финальными.

## Локальный запуск

Это статический сайт без сборщика. Открой `index.html` через локальный HTTP-сервер, например:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

Тесты:

```bash
npm test
```
