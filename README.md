# Fury Lab — калькулятор персонажа

Точная копия исходного сайта https://fury-stat-lab.sidoors.chatgpt.site/.

## Исходная версия

Перенесено 837 файлов из Sites без изменений содержимого.
Исходный коммит: `e949a8bb2e75a90535d3e9a14b80a56948e62b1a`.

`dist/` содержит готовый статический сайт: интерфейс, каталоги, локальные иконки, расчёты характеристик, мастерство, руны и симулятор боя.
`tests/` содержит исходные проверки. Обоснование формул — в `MATH-AUDIT.md` и `SIMULATION.md`.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:8000. Требуется Python 3; установка npm-зависимостей не нужна.
Для проверок нужен Node.js 22 или новее:

```sh
npm test
```

## Публикация

GitHub Pages публикует папку `dist` при обновлении `develop`.
Рабочая ветка — `develop`, стабильная — `master`.

Сборки сохраняются в localStorage браузера. При переходе с исходного адреса использовать экспорт JSON на старом сайте и импорт на новом.

Файлы лицензии и прежняя история GitHub сохранены. Каталоги и игровые изображения перенесены из исходного проекта; права третьих лиц на них не меняются.
